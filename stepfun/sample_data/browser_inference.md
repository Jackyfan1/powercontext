# 端侧推理与 WebGPU

在浏览器里运行神经网络依赖 WebGPU 与 WASM 两种执行后端。

WebGPU 直接调用显卡驱动，适合矩阵乘法密集的 Transformer 推理。主流桌面浏览器在 2023 年之后陆续开放 WebGPU，移动端支持稍晚。使用前应检测 navigator.gpu 是否存在，并尝试请求 adapter，只有拿到 adapter 才能确认可用。

WASM 后端基于 CPU 执行，兼容性最好，几乎所有现代浏览器都支持。开启跨源隔离（COOP/COEP）之后可以使用 SharedArrayBuffer，让 WASM 多线程并行，显著提升推理速度。

# 降级策略

工程上应当优先尝试 WebGPU，失败时自动降级到 WASM。降级后要在界面上明确提示用户当前使用的后端，避免用户误以为仍在 GPU 上执行。

衡量推理性能时可以关注三个指标：模型加载耗时、单条文本的编码耗时、以及批处理吞吐。不同后端、不同精度下这三个指标差异很大。

# 与数据库的配合

端侧推理负责把文本变成向量，向量需要落到本地数据库里才能被反复检索。浏览器不能直接讲 MySQL 协议，因此常见做法是由本机启动一个轻量后端进程，连接 seekdb 负责存取，浏览器只负责推理与展示。
