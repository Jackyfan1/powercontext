# RAG 知识库的工程流程

一个最小的个人知识库应用包含四个步骤：导入语料、切块向量化、写入数据库、检索并展示。

导入语料阶段要处理编码、段落切分与去重。切块长度需要在语义完整与检索精度之间折中，中文场景通常取 200 到 400 字，并对超长段落按句号切分。

向量化阶段把每个分块编码成固定维度的向量。为了保证隐私，向量可以在浏览器本地计算，只把向量和原文一起交给本地数据库。

写入阶段需要同时保存原文、向量与元数据（标题、来源、分块序号）。元数据用于结果展示与增量更新。

# 增量导入

增量导入指后续新增的文档不需要清空重建。新文档写入后应当立刻能被检索命中，索引刷新只是更新统计信息与执行计划，而不是全量重建。

# 会话状态

知识库应用通常还需要保存会话状态：当前选中的集合、历史查询、上次的检索结果。这些状态存到数据库而不是只放在内存里，刷新页面后才能恢复。
