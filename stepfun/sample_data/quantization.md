# 模型量化基础

量化是用低比特数据类型表示模型权重的技术。常见的三种精度是 FP32、FP16 与 INT8。

FP32 使用 32 位浮点，是训练时的默认精度，也是质量基准。FP16 使用 16 位半精度浮点，体积减半，在支持 FP16 计算的显卡上速度更快，质量通常只有极小损失。

INT8 使用 8 位整数，配合每个通道的缩放因子（scale）与零点（zero point）把浮点区间线性映射到整数区间。体积约为 FP32 的四分之一，CPU 上还能利用整数指令集加速。变换器模型通常采用动态量化或静态量化两种方案。

# 质量评估

量化后需要评估质量变化。常见做法包括：对比量化前后 embedding 的余弦相似度、比较检索 Top-1 命中是否一致、以及在标注数据上评估召回率。

对 embedding 模型而言，只要量化前后同一句话的向量夹角足够小，检索排序通常保持稳定。经验上 INT8 动态量化的平均余弦相似度可以保持在 0.99 以上。

# 体积与收益

以 bge-small-zh-v1.5 为例，FP32 版本约 95 MB，FP16 约 47 MB，INT8 约 24 MB。端侧场景下，体积直接决定了首次加载时间与缓存占用，因此 INT8 往往是默认选择；如果设备支持 WebGPU，则 FP16 在速度与质量之间更均衡。
