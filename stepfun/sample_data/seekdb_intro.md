# seekdb 简介

seekdb 是 OceanBase 推出的轻量级数据库，面向 AI 应用与端侧场景。它保留了 OceanBase 的分布式内核能力，同时把部署成本压缩到单机单进程，适合在笔记本或边缘设备上直接运行。

seekdb 采用 MySQL 协议对外提供服务，默认端口 2881，因此可以直接使用 pymysql、mysql 客户端等成熟工具连接。它兼容大部分 MySQL 语法，包括 JSON 类型、事务与常见索引。

# 检索能力

seekdb 同时支持向量检索与全文检索两类索引。

向量检索方面，seekdb 提供 VECTOR 字段类型，并支持 HNSW 图索引。建表时可以声明 distance 度量方式，例如 cosine 余弦距离，然后通过 cosine_distance 函数在 SQL 中计算相似度。

全文检索方面，seekdb 支持 FULLTEXT 索引，并且提供 ngram 分词器，可以在中文语料上直接使用 MATCH ... AGAINST 语法，无需额外部署分词服务。

# 混合检索

混合检索把向量相似度与关键词相关度结合起来，既保留语义召回能力，又能对专有名词、编号等精确匹配做补强。

在 seekdb 中可以在一条 SQL 里同时完成两路召回：向量分数用 1 减去 cosine_distance 得到，全文分数用 MATCH AGAINST 得到并做归一化，然后按权重加权排序。这样检索完全在数据库内完成，应用层不需要回传候选集再重排。

# 适用场景

seekdb 适合个人知识库、文档问答、代码检索、端侧智能助手等场景。数据规模从几千条到上千万条都可以通过调整索引参数适配。

对于端侧应用，seekdb 可以作为本地数据层，与浏览器或桌面端的本地推理能力配合，形成完全离线的 RAG 流程。
